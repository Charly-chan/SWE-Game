# Evaluation

- [`evalsys/`](evalsys/README.md): Python evaluator and command-line interface.
- [`harness/`](harness/README.md): Godot probes and replay drivers.
- [`interface/`](interface/README.md): agent submission contracts.
- [`tasks/`](tasks/README.md): fixed routes, certificates, and scoring baselines.
- [`routes/`](routes/README.md): route registry.
- [`taskgen/`](taskgen/README.md): fixed visual rubrics.
- [`tools/`](tools/README.md): runtime checks and reporting utilities.
- [`infra/`](infra/README.md): Unity evaluation environment.

Run `eval/evalsys/bin/bench --help` for supported commands.
