# Contributing

For a runtime bug, include the evaluator commit, dataset revision, task ID,
command, and a minimal report that reproduces the issue. Remove credentials and
private provider responses before sharing logs.

For code changes, describe the resulting behavior and run relevant tests under
`eval/evalsys/tests/`. State any effect on task inputs, evidence collection,
score weights, or ranking eligibility. Preserve third-party notices and report
new dependencies or assets with their applicable license terms.
