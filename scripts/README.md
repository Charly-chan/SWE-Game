# Scripts

- `fetch_reference_data.py`: download a released reference project and optional video.
- `run_coding.sh`: launch a coding-agent task.
- `run_harbor.sh`: launch tasks through Harbor.
- `check_release.py`: check the public checkout, links, data manifest, and task inventory.

The main user entry points are [`../setup.sh`](../setup.sh),
[`../run_benchmark.sh`](../run_benchmark.sh), and [`../evaluate.sh`](../evaluate.sh).
