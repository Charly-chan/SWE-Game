# PixelSabotageAdventure


A retro stealth game (inspired by No one lives forever 2, but without the player having guns) made for Godot Wild Jam 93

I initially wanted to add several features found in Nolf2 like throwing coins to distract guards, tracking darts or lock picking, which I plan to add in a future post jam update version. Also I really had a really cool idea for a secret room (see wildcards), which I didn't add, and which might be added in this post jam update.

It was already quite a journey to develop the enemy patrol / chase / navigation system, including the 2,5D rendered sprite that shows a different image from the sprite sheet depending on the view angle.


With a few exceptions I did everything myself and from scratch
