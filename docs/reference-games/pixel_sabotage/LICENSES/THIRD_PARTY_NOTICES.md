# Third-Party Notices

Evidence was checked on 2026-08-27. The shipped game contains no music; the upstream
CC-BY-SA 3.0 Endgame Singularity tracks were removed from the runtime closure.

## Upstream Project

PixelSabotageAdventure code and author-created art are distributed under MIT by
rubberduck99. The exact bundled text is `UPSTREAM_MIT_LICENSE.txt`. Benchmark adapter
changes are also distributed under that license boundary. The excluded Maaacks template is
MIT; its preserved text is `MAAACKS_TEMPLATE_MIT.txt`.

## SubspaceAudio Sound Effects

The upstream README identifies the retained sound effects as SubspaceAudio's "512 Sound
Effects (8-bit style)" under CC0:
https://opengameart.org/content/512-sound-effects-8-bit-style

## Kenney Assets

The upstream README identifies Kenney icon graphics. The retained `Kenney Future.ttf` is
from Kenney Fonts, and the retained UI/item images are Kenney graphics. Kenney's official
asset pages mark these packs CC0:

- https://kenney.nl/assets/kenney-fonts
- https://kenney.nl/assets/pixel-ui-pack
- https://kenney.nl/support

Attribution is not required by CC0, but is retained here as "Kenney".

## Quaternius Guard Source

The guard sprite sheet is a pixel render made upstream from the Quaternius Ultimate Modular
Men Pack. The official pack page marks the source models CC0:
https://quaternius.com/packs/ultimatemodularcharacters.html

## Jersey 15

`data/fonts/Jersey15-Regular.ttf` is the Google Fonts Jersey 15 file by the Soft Type
Project. It is licensed under SIL Open Font License 1.1. The license and copyright notice are
preserved verbatim in `JERSEY15_OFL.txt`:
https://github.com/google/fonts/tree/main/ofl/jersey15

## Environment Textures

The upstream README states that the exceptional third-party environment textures are CC0
textures from OpenGameArt and other established texture sites. The snapshot does not preserve
per-texture download URLs. `assets/ASSET_SOURCES.md` records this limitation on every retained
texture row and binds each byte to the source snapshot with SHA-256; no more specific origin is
asserted.
