# Versioning and reproducibility

A benchmark run is identified by the evaluator commit, pinned dataset revision,
scoring registry, agent/model version, input settings, budgets, and judge
configuration. Preserve those identifiers with submissions and evaluation reports.

The fixed task catalog and checksums are in [`data/task-data.json`](../data/task-data.json).
See [data downloads](reference-data.md) and [third-party notices](../THIRD_PARTY_NOTICES.md).
